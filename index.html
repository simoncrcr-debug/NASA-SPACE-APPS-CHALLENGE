03 — DATOS EN VIVO · NASA/JPL

¿Estamos en peligro?

Consulta acercamientos cercanos a la Tierra
calculados por el sistema CNEOS de NASA/JPL.

ⓘ

Un acercamiento no significa un impacto. Esta consulta muestra encuentros dentro de 0,05 UA durante los próximos 30 días; no es una evaluación completa de riesgo. Para el riesgo de impacto, consulta Sentry.

Pulsa para solicitar datos actuales.
Los datos se cargarán desde la API de acercamientos CNEOS de NASA/JPL.
FUENTE: NASA/JPL SBDB Close-Approach Data API · Datos sujetos a actualización e incertidumbre orbital.

05 — ARCHIVO PÚBLICO

Explora SPHEREx.

SPHEREx cartografía el cielo en luz infrarroja cercana. El archivo de NASA/IPAC-IRSA publica imágenes espectrales y cubos del cielo, con releases que se actualizan.

El archivo requiere una posición para buscar. La búsqueda abre el servicio de IRSA; aquí no descargamos ni procesamos datos científicos.
